# GaGa Chat — Product Overview

## Purpose & Value Proposition

GaGa Chat is a production-ready, real-time social chat application targeting mobile and desktop users who want an all-in-one social communication platform. It combines messaging, social media, live streaming, voice rooms, and a creator economy with a built-in wallet/gifting system.

Live at: https://oumagachat.web.app | https://gagachat.app

## Key Features & Capabilities

### Messaging
- 1:1 and group real-time chat (Supabase Realtime)
- Disappearing messages, message pinning, saved messages
- Voice messages, media sharing (Cloudinary)
- Offline message queue with background sync
- Typing indicators, read receipts, presence/online status
- Broadcast lists, scheduled messages, message rate limiting
- AI chat assistant (AIChatPage)

### Social / Content
- Stories (24h ephemeral content)
- Reels (short-form video feed)
- Timeline / posts with reactions and comments
- Hashtags, bookmarks, search
- Daily challenges, events, marketplace

### Live & Voice
- Live streaming with WebRTC (Supabase signaling)
- Voice rooms (multi-participant audio)
- 1:1 video/audio calls with call overlay

### Creator Economy
- Creator Center & Dashboard
- GaGa Rewards program
- Premium subscriptions
- Wallet: send money, request tips, split bills, withdraw, QR scanner

### Platform
- PWA (installable, offline-capable, push notifications)
- i18n (English + Spanish via i18next)
- Dark mode
- Content moderation hook
- Analytics (Firebase Analytics + GA4)
- Admin page

## Target Users

- Social media users wanting an integrated chat + content platform
- Content creators monetizing via tips, gifts, live streams
- Friend groups using voice rooms and group chats
- Mobile-first users (PWA installable)
