# GaGa Chat latest source status — self-hosted calling

This update supersedes the earlier ZEGO-based fixes report.

## Implemented
- Removed ZEGO dependency, browser hook/configuration, token services and integration guide files.
- Added native one-to-one WebRTC client, Alibaba-deployable WebSocket signaling gateway, and short-lived authenticated coturn credentials.
- Added caller/callee signaling validation, call-membership checks, heartbeat, payload/rate limits and TLS/reverse-proxy/service templates.
- Added microphone/camera tracks, remote audio/video, mute, camera toggle, hold/resume, camera switching, hangup cleanup and user-action audio playback recovery.
- Media permission failure no longer marks an incoming invitation connected.
- Removed misleading speaker/earpiece switching and replaced it with honest device audio-output guidance.
- Added shared offline status, guarded error-page refresh recovery and consistent call-history accessibility/counting.
- Removed automatic demo-reels substitution and mock advertisement carousel from the production feed.
- Retained prior message/offline/reconnect/database retry fixes.
- Removed SDK eval requirement from CSP and allowed the configured default calling gateway origin.

- Added calling gateway health checks before outgoing invitations and incoming acceptance.
- Prevented concurrent outgoing call starts and reused a stable invitation UUID across retries/lost acknowledgement recovery.
- Added a portable fail-fast release verifier, removed source maps from hosting output, and aligned package/service-worker/manifest versions.

- Added four-attempt signaling recovery with fresh tokens and offer rollback, 45-minute TURN renewal, and WebRTC stats quality reporting.
- Recovery and renewal work stop on hangup; revoked/replaced sessions do not retry.
- Call-history deletion retains failed records and reports errors rather than displaying success. Missing/group participants cannot trigger misleading callback actions.

## Checked
141 frontend tests passed across 16 files. Three backend tests passed, including real local WebSocket SDP/ICE exchange with a mock identity verifier. TypeScript and production bundling passed using the real public Firebase/Supabase configuration recovered from the current live app. Release 1.0.2 has a verified hosting folder and SHA-256 manifest. Modified server JavaScript syntax passed. A real TURN relay, microphone/camera exchange between physical devices, production auth/RLS, regional routing and live deployment have not been verified.

## Not yet complete
The source archive differs from the current live deployment and must be reconciled before publishing. Existing Supabase identity, invitations and history remain; Alibaba currently owns the new signaling/relay design, not all application data. No Alibaba deployment access or authenticated Firebase account is available here. The calling gateway returned HTTP 502 at release preparation. Nothing was published. See HOSTING-RELEASE.md for preview/promotion instructions. The README in alibaba-calling contains deployment templates and required live checks. Group calling is explicitly unavailable. Live-stream and voice-room media still require migration. Bounded signaling recovery, periodic relay renewal and client QoS sampling are now implemented with lifecycle tests. Real-device recovery/long-call validation, native Android background calls, production QoS/load tests, monitoring and complete regional rollout remain follow-up work. No APK/AAB was built in this update.

The inventory report SCREEN-IMPROVEMENT-MAP.md covers the 51 page modules and additional auth/desktop views. It is an implementation map, not a claim that every feature has been rebuilt or validated.
